# 🚀 Озвучка Ai Pro — выкладка в интернет и git

Сайт лежит на **Cloudflare Pages** (бесплатно, постоянный адрес `https://ozvuchka-ai-pro.pages.dev`, HTTPS — нужен для рендера).
Вход **пока открыт** (решение 22.10.2026): ключ Polza, проекты и голоса хранятся только в браузере каждого посетителя, в коде сайта их нет, поисковики сайт не индексируют. Закрыть вход можно позже — шаг 5.

---

## Один раз: настройка

### 1. Аккаунт Cloudflare
Зарегистрируйтесь на https://dash.cloudflare.com/sign-up (бесплатный план).

### 2. Вход из компьютера
В папке проекта (терминал):
```
npx wrangler login
```
Откроется браузер → «Allow». Проверка: `npx wrangler whoami` показывает вашу почту.

### 3. Создать проект Pages
```
npx wrangler pages project create ozvuchka-ai-pro --production-branch main --force
```
`--force` нужен только здесь, один раз: с 2026 года Cloudflare по умолчанию переводит Pages в Workers, а этот флаг создаёт обычный проект Pages с адресом `*.pages.dev`. Если имя занято — придумайте другое и поменяйте `--project-name` в `deploy.cmd`.

✅ Уже сделано 22.10.2026: проект `ozvuchka-ai-pro` создан, сайт выложен на https://ozvuchka-ai-pro.pages.dev

### 4. Первая выкладка
Двойной щелчок по **`deploy.cmd`**. В конце будет адрес вида `https://ozvuchka-ai-pro.pages.dev`.

### 5. Закрыть паролем (Cloudflare Access) — отложено
Проще всего через проект: Workers & Pages → ozvuchka-ai-pro → Settings → Access policy → Enable, затем в созданном приложении Access добавить домен без звёздочки `ozvuchka-ai-pro.pages.dev`. Проверка — окно инкогнито должно показать вход Cloudflare.

Или вручную:
1. https://one.dash.cloudflare.com → Zero Trust. При первом входе: придумать имя команды, выбрать план **Free** (Cloudflare может попросить привязать карту, на бесплатном плане денег не списывает).
2. **Access → Applications → Add an application → Self-hosted.**
3. Application domain: `ozvuchka-ai-pro.pages.dev`. Добавьте второй домен: `*.ozvuchka-ai-pro.pages.dev` — это закроет и тестовые адреса выкладок.
4. Policy: Action **Allow**, Include → **Emails** → ваша почта.
5. Login methods: **One-time PIN** (код на почту) — уже включён по умолчанию.
6. Сохранить. Проверка: откройте адрес в окне инкогнито — должна появиться страница Cloudflare с вводом почты.

Сессия живёт 24 часа (можно увеличить в настройках приложения, Session Duration).

### 6. Перенести данные со старой версии
Ключ, проекты и «Мои голоса» хранятся **в браузере и привязаны к адресу**. На новом адресе всё будет пустым:
- откройте `index.html` с диска двойным щелчком — Chrome хранит данные всех локальных файлов вместе, поэтому там должно быть всё, что было в старом `voiceover.html` (если пусто — достаньте старый файл: `git show d39bb8c:voiceover.html > old.html` и откройте его);
- там: «Сохранить проект» → .json и «Мои голоса» → экспорт .json;
- на новом адресе: ввести ключ Polza, открыть проект и импортировать голоса.

На каждом новом устройстве (телефон, ноутбук) — то же самое: ключ вводится один раз, проекты переносятся файлом .json.

## Каждый день

| Что | Как |
|---|---|
| Открыть локально | двойной щелчок по `index.html` (всё работает и без интернета-сервера) |
| Сохранить версию в git | `git add -A` → `git commit -m "что сделал"` |
| Выложить на сайт | `deploy.cmd` |
| Посмотреть историю | `git log --oneline` |
| Откатить файл к прошлой версии | `git checkout <хэш> -- js/tts.js` |
| Отменить все несохранённые правки | `git restore .` |

Каждая выкладка Cloudflare тоже хранится: в панели Pages → Deployments можно в один клик вернуть любую прошлую.

## Как устроены файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `css/style.css` | оформление |
| `css/fonts.css`, `fonts/` | шрифты интерфейса и субтитров (свои файлы, без Google Fonts) |
| `js/core.js` | общие помощники (время, тосты, скачивание, localStorage) |
| `js/models.js` | списки моделей Polza, голоса, цены |
| `js/state.js` | состояние проекта, автосохранение, переключатели |
| `js/video.js` | видео, превью, панель «Сейчас» |
| `js/cues.js` | реплики: действия, списки, импорт/экспорт текстом |
| `js/timeline.js` | таймлайн, кадры, горячие клавиши |
| `js/polza.js` | запросы к Polza AI, ИИ по отрезкам |
| `js/script.js` | шаг 2 — сценарий, перевод, ИИ пишет текст |
| `js/phrases.js` | шаг 3 — сценарий → фразы |
| `js/tts.js` | озвучка (TTS, ElevenLabs, ускорение без смены тона) |
| `js/effects.js` | акцент, характер, звуковые эффекты |
| `js/voices.js` | карточки голосов, «Мои голоса» |
| `js/playback.js` | кэш озвучки, поиск речи, прослушивание с видео |
| `js/export.js` | экспорт WAV / SRT / копия видео |
| `js/subs.js` | субтитры |
| `js/whisper.js` | точное время слов (Whisper в браузере) |
| `js/style.js` | стиль видео (цвет, слои) |
| `js/ui.js` | свёрнутые блоки, полный экран |
| `js/music.js` | фоновая музыка: дорожка, громкость, приглушение под голосом, сведение в рендере |
| `js/render.js` | рендер mp4 |
| `js/main.js` | проект и запуск страницы |

Это обычные скрипты (не модули): подключаются по порядку в конце `index.html` и видят переменные друг друга. **Порядок важен** — код, который выполняется сразу при загрузке, может использовать только то, что объявлено в файлах выше.
